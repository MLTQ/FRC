# Physical inertia inverse controls

Substitutes modal-inverse corrections into the independently applied complete
physical H+A*I A operator, using actual weak Ampere and inertia actions. Random
directions test uniform exactness, positive work and symmetry. No assertion
uses the modal symbol assembly to define its expected result.

Two different nonuniform perturbed states compare old/new full RHS fluid, B/J/E
and unchanged strict induction residuals, including reuse of the fixed inverse
after changing actual density. Fluid rates must be bitwise identical; solved
magnetic/current/electric differences must lie within the original solve bound.
