# Independent localization verification

Analytic vector (r,r*cos(6*pi*z/L),0) in a cylinder has exact component power
fractions 2/3,1/3,0 and Fourier power only at indices0,+/-3. Its radial measure
is r^3 dr, giving exact axis/wall-element and outer-cell fractions. The test
checks physical cylindrical normalization and complete spectral distribution,
independently of any trajectory, production field or saved diagnostic output.
