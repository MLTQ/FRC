# Moment reconstruction checks

Independent analytic annular integrals verify even, radial-odd and angular
polynomials through degree three in r²/2, including axis and wall samples.
Analytic periodic cell averages verify axial fourth-order convergence. A true
linear slow compressible mode tests near cancellation in mass divergence using
rho0 v1 cell averages; it isolates spatial error from quadratic wave terms.
This test concerns a candidate continuity interpolator, not a coupled solver
change or an assertion of positivity/stability for discontinuous flow.
