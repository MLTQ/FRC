# Non-Beltrami current-inertia reference checks

Checks analytic drift against the existing independent physical toroidal curl,
the full convective/kinetic-gradient identity, and agreement of full/reduced
electric curls. Independent fourth-order spatial differentiation validates the
complex-step forcing. Uniform and varying density are separate controls, and
the forcing must be nonzero so the helical wave's cancellation cannot pass it.
No numerical production operator supplies the expected reference values.
