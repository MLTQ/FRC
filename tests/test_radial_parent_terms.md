# Parent-term independent controls

Compares each analytic ideal/Hall/pressure/inertia negative curl with an
independent fourth-order finite difference of its full cylindrical electric
field at off-grid points. Checks the summed E against the existing original
reference and summed momentum/induction against its independently solved mode
rate. No production spatial operator defines the expected result. Errors of
the resolved Fourier reference and differentiation remain bounded explicitly.
