# Instrumentation invariance

Runs the original and instrumented balanced core with the same nonuniform
physical density, uniform metric inverse and fixed random forcing. Every
accepted B/J/E coefficient, residual, iteration/refinement count must be bitwise
unchanged, with atomic input preservation and finite saved observations.
This validates observation-only behavior, not continuum accuracy or recovery.
The separate exact radial256 rejected-input probe must also match the original
first-attempt failure message and every residual exactly.
