# Workflow integration checks
Validated configurations must round trip through JSON. Waveforms must have the
declared common vacuum center peak. Independent repeated runs and archive reads
must reproduce every array exactly; metadata may contain timestamps but no
nonstandard JSON infinities. Mixed solver energy residuals remain small. Zero
bias yields undefined reversal and Stage 0 never fabricates current. Aligned
material boundaries preserve axial reflection symmetry despite float rounding.
Reversing all sources and bias preserves oriented reversal criteria. Decimal
duration/dt inputs do not introduce a spurious integration step.
