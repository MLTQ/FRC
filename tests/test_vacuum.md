# Vacuum verification
Analytic on-axis fields, independent adaptive Biot–Savart quadrature, integrated
axial flux, symmetry, far dipole limit, superposition, polarity and Faraday law
test the loop kernel independently. Grid refinement verifies nodal field
reconstruction; face divergence tests the topological flux identity. Singular
filaments must fail explicitly. Stage 1 must not be started before these pass.
