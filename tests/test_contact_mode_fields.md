# Strong cylindrical curl check

The analytic magnetic polynomial psi=x(X-x), Btheta=0.23 r has Br=0,
Bz=X-r² and curl B=(0,2r,0.46). Independent root-polynomial magnetic sampling
and differentiation must reproduce this original cylindrical identity through
the axis-adjacent and wall cells. This checks the physical strong-curl audit;
it does not assert that weak Ampere current equals that curl at unresolved
boundaries or interfaces.
