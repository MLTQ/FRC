# Observation of split-inverse residual arithmetic

`observe` records the actual normalized operator/dual gap and separately
evaluated H/T, current/inertia, electric-addition, curl and dual-projection
contributions at one original iterate. No diagnostic enters acceptance or
changes a state. Signed vector sums and unexplained remainders accompany norms.

The two-sum low part measures bits lost by the electric addition; its propagated
curl is distinguished from matrix-action distributivity. Full actual arrays
are archived so this arithmetic observation can be independently checked.
Use only with the documented current split-inverse core. Frozen earlier
balanced-core observations describe a different arithmetic path.
