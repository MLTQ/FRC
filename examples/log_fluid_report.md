# Diagnostic scientific figure

Renders six panels from completed, retained records: baseline contact failure
versus half-step radial-work completion, actual acoustic spectra, separated
energy accounts, independent component/axis convergence, uniform translation
chain-rule defect, and a nonlinear characteristic wave comparison. The figure
does not include or imply completion of still-running remote studies. It labels
the unresolved radial force accuracy and restricted hydrodynamic scope.
Log-grid resolution panels label only the four tested cell counts to avoid
overlapping automatic minor tick labels.
