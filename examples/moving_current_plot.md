# Physical moving-rate refinement figure

Plots independently measured whole-volume and first-annulus relative L2 errors
for Bdot, Jdot and full electric field. Physical argon/electron, original-density
and explicit massless controls remain separate. It reads audited records; it
never computes or changes a numerical solution. The caption states that these
are manufactured instantaneous rates rather than a moving trajectory or
formation experiment. The noninteractive Agg backend permits unattended report
generation on macOS. The report hashes the resulting PNG for visual review.
