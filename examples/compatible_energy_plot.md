# Compatible-energy scientific figure

Plots unchanged-shock profile error and independent energy error against the
historical local method, fixed-grid RK/CFL controls, the same prescribed pulse's
source-normalized budget, independent quadratic RK predictions, and smooth
analytic convergence. These are measured simulation results, not illustrations.

Incomplete or failed runs are excluded from final-time curves. Signed values
remain in the report/records; logarithmic error panels use absolute values.
Historical data carry their original source fingerprint. Previewing available
cases is permitted, but the final report driver requires the full configured
dataset and all configured time audits. Output is a standalone PNG, which must
be visually inspected before delivery.
If present, explicit boundary-strip probes appear as separate experimental
curves, including their fixed-grid time comparison. They have no source-pulse
curve because those source/boundary controls are not yet verified for the probe.
The first two shock panels share the first panel's method legend, keeping the
small residual curves visible rather than covering them with a duplicate box.
