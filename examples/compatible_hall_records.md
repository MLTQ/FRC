# Compatible Hall scientific records

Hashes all actual production/reference/measurement dependencies plus versions.
Source identity must remain fixed through each case and the full protocol.
Saves ordinary strict JSON and lossless NPZ with exact configuration and archive
hash. A case is marked completed only after its measurements finish. Relative
norms return null for exactly zero reference norm, without an arbitrary floor.
No source, convergence limit or partially evolved case is silently relabeled.
