# Guarded tangent calculation and replay

`run(kind, destination, control, inputs, original=None)` dispatches only the
explicit `probe` or `audit` tangent modules. Probe inputs are the original
trajectory and complete trajectory verification; audit input is the completed
probe. The selected dynamic module and all temporary fixture/provenance
dependencies are explicit source seeds, frozen before execution. A later
audit module is not implicitly part of an earlier probe's source closure.

One own-process monitor observes cumulative macOS RSS and available disk every
second, enforcing8GiB/256MiB limits. It sends SIGINT on violation, then exits
only its own process with130 after five seconds if native work has not yielded.
Final extrema must also pass. Atomic control summaries refresh every30 monitor
observations; a heartbeat is not proof a process remains live. The actual
process handle must still be polled and its terminal exit collected.

`--original` performs the existing full diagnostic verifier plus raw-file SHA
equality after a fresh complete calculation. Replayed RHS exceptions remain
exceptions and never count as accepted derivative cases. Incomplete resource
interruptions and propagated workflow errors cannot pass the guard's complete
protocol status. Every partial archive remains. No retry, tolerance relaxation,
state filtering, atmosphere, floor, artificial mass or energy repair is added.

Control/runtime/resource observations are separate from scientific replay
metrics. Run one large probe/audit at a time and never alongside the live
trajectory replay. This wrapper does not establish physical accuracy; the
independent continuum control, amplitude and quadrature comparisons, full
trajectories and all original formation-sandbox gates remain required.
