# Resource guards for spatial contribution workflows

Runs either the complete signed contribution collector or its independent
physical audit in its own process. Explicit module seeds archive both the
guard and actual scientific source. An optional original directory invokes
the established complete raw/metric replay verifier after the workflow.

The guard monitors this process's cumulative maximum RSS (macOS bytes) and
free disk each second, with final observations. Limits stay8GiB/256MiB.
Insufficient resources interrupt the current process and preserve records;
they are distinguished from individual separated induction rejections.
The user-facing original full RHS acceptance is never relaxed to fit a budget.
Original and replay paths must be fresh. A verification record certifies
reproduction, not continuum accuracy, completed formation or physical stability.

The fixed workflow names are `parts` and `audit`; this is not an arbitrary
module execution service. Only one heavy research process should run at once.
