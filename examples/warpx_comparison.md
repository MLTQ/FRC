# Isolated WarpX benchmark driver

Runs one case per Python process because WarpX initialization is process-global.
This optional example imports WarpX only inside `run`; it changes no production
dependencies. Copy this file and `backend_wave_reference.py` into an `examples`
folder alongside the external environment; invoke with `python -m examples.warpx_comparison`.

Two verification fixtures are explicitly different models:
- `hall`: cold kinetic proton particles, inertialess zero-pressure electrons,
  uniform n=1e18 m^-3, B0=.001 T, k di=1, both circular helicities, periodic z.
  Quiet uniform loading, first-order particle shape, no smoothing, eta=0 and
  hyper-resistivity=0. Positive density everywhere makes the explicit denominator
  floor inactive; this case says nothing about hybrid vacuum behavior.
- `vacuum`: full Yee Maxwell equations, no particle species at all, periodic
  traveling wave Ex=c By. This exercises actual vacuum but not a moving edge.

Hall uses collocated fields and 10 RK4 magnetic substeps per particle step.
The initial electric field is Ex=(omega/k) By, Ey=-(omega/k) Bx, Ez=0,
consistent with both cold Ohm's law and Faraday. WarpX uses it to desynchronize
particle velocities before depositing the initial hybrid current. Omitting it
produces a different initial half-step and first-order startup contamination;
that control is preserved separately, not attributed to the physical solver.
The electromagnetic fixture uses native Yee staggering and a fixed CFL.
The device arena starts at 64 MiB; these fixtures do not need a large reservation.
WarpX-specific simulation keywords use the explicit `warpx_` PICMI prefix.
Analytic vacuum initialization explicitly specifies all six components, including
zeros; WarpX's parser requires them once parsed field initialization is enabled.
Coordinates retain nodal versus cell-center staggering and drop only the
duplicate periodic endpoint. Field errors are against continuum solutions,
not a reference trajectory generated by either production solver.

The case directory must be new. Archives contain all initial/final vector
fields and positions, full driver arguments, native inputs, source hashes and
native energy diagnostic files.
Completion requires the native accepted step count and time to match the request.
Timing separates initialization from evolution plus synchronous host readback;
it includes diagnostics and is not a throughput comparison with a four-mode
linear solver. Remote build identity belongs in the comparison manifest.
For Hall, endpoint particle weights/proper velocities are independently archived.
Perturbation energy includes transverse magnetic and physical ion kinetic energy;
constant background magnetic energy is excluded so it cannot dilute errors.
The massless cold electrons contribute no thermal/drift energy in this fixture.
