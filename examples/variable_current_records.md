# Variable-density study provenance

Follows the local transitive imports of production, driver, reference, independent
physical norms, replay audit and focused tests. Hashes each source and the sorted
mapping, records runtime versions, and archives source plus companion documents.
The driver freezes these before work and rejects source changes before completion.
Raw per-case arrays have independent SHA-256 identities. No old study's source or
outputs are overwritten. This archive is local and does not imply publication.
