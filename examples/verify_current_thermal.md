# Current/thermal verification report

Requires strict protocol/source/field/history and independent physical replay
before comparisons or figures are produced. Recomputes the principal-symbol
scan exactly from frozen sources. Reports every case audit, numerical-reference
time and physical mesh comparisons, true successful/rejected count, all-history
energy/entropy drifts, source hashes and scientific figure hashes.

The report is a separate read-only analysis layer. Its source changes never
relabel old measurement provenance. A report pass means archival/physical replay
checks passed; the measured physical errors and fixed-bulk scope remain explicit.
Both generated figures require visual inspection before results are summarized.
