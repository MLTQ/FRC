# Read-only moving-current archive audit

Reconstructs every initial condition from the independent analytic reference;
checks exact configuration, source fingerprint, record/archive hashes and finite
arrays. Successful results replay Ampere, full-electric Faraday, scalar-potential
restoration, work and independent physical field norms. Direct cylindrical
Faraday differences avoid the production curl map. Norm quadrature increases
from order 8 to 12; sampled maximum errors at the two orders are retained but
are not asserted identical because sample locations differ.

Omission controls replay the changed equation and measure their physical rate
change. Rejected records retain only original inputs and explicit failure.
The initial incomplete attempt is separately checked against its hashed source
snapshot and logs, never relabeled as a current successful measurement.
This module writes no trajectory or physical state and does not run an evolution.
