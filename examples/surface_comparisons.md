# Reproducible overlap-integration cache

Computes paired order-4/order-6 common-cell-overlap comparisons once and retains
both unrounded results. Every cache record contains the complete two input
records (including configurations and checked field hashes) and exact hashes of
all comparison/sampling/clipping/cache sources. Reuse requires exact identity
and completion. Analysis source changes during work raise explicitly.

The `--base` mode analyzes only the original completed 20-case protocol while
the supplemental time control runs. It does not call that larger study complete.
Full report assembly requires all input records and every declared pair.
Separate report/figure edits do not invalidate these costly scientific
diagnostic integrations when their actual algorithms and input arrays match.
