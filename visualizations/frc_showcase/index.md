# Scientific showcase page

Offline dark two-panel presentation for the current-density volume and magnetic
flux-density lines. Legends have SI units and common time-independent ranges.
Captions distinguish the initialized FRC verification fixture, axisymmetric
revolution, unresolved heated edge and illustrative rendering choices.

The export builder embeds data and local renderer/controller scripts into this
template. Browser controls synchronize camera, change among actual saved times,
toggle rotation/cutaway and save a labeled poster. There is no CDN, analytics,
external image, third-party script or remotely loaded font.

The cutaway toggle is initially enabled and its accessible state agrees with
the renderer. Both panels retain their physical limits when changing time.

Titles, canvases and interpretation notes occupy separate layout regions so
exterior field lines cannot obscure scientific labels.
